# ITNT415 Calculator Master

**Student Name:** Raeven Villegas
**Course and Section:** S-ITNT415

## Project Description
A menu-driven Python calculator built using Git and GitHub branching. Each arithmetic operation (addition, subtraction, multiplication, division) was developed on its own feature branch and merged into `main` via a Pull Request.

## Branch Structure
- `main` — integrated final calculator
- `addition_Villegas` — addition feature
- `subtraction_Villegas` — subtraction feature
- `multiplication_Villegas` — multiplication feature
- `division_Villegas` — division feature (includes division-by-zero handling)

## Program Features
- Menu-driven interface (Add, Subtract, Multiply, Divide, Exit)
- Input validation for non-numeric entries
- Division-by-zero error handling
- Continuous execution loop until user selects Exit
